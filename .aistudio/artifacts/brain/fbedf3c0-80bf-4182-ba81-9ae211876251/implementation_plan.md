# Не дивись у землю — Психологічний інді-хорор

Повноцінна 2D психологічна хорор-гра українською мовою з боковим скролом, багатошаровим паралаксом, процедурною векторною графікою силуетів на Canvas 2D, синтезованим звуковим оточенням через Web Audio API, розгалуженими діалогами та динамічною шкалою тривоги.

## Користувацькі рішення та налаштування

> [!IMPORTANT]
> На основі відповідей на етапі опитування зафіксовано такі параметри та конфігурації:

- **Рівень хорор-ефектів**: Підвищений хорор — частіші хроматичні глітчі, спалахи червоного кольору, тремтіння камери (camera shake) та посилене мерехтіння ліхтаря.
- **Швидкість діалогів**: Атмосферний ефект друкарської машинки з миттєвим пропуском репліки натисканням клавіші «Пробіл» або тапом/кліком.
- **Мобільне керування**: Віртуальні ергономічні наекранні кнопки руху («Вліво», «Вправо») та взаємодії («Дія / E») з оптимізованими зонами натискання.

## 1. Загальний огляд та концепція

- **Що це таке**: Повноцінна сюжетна 2D гра без боїв та екшену, де жах досягається через напружену атмосферу, звуки кроків і серцебиття, звуковий ландшафт дощу та вітру, темряву навколо променя ліхтаря та поступове розкриття моторошної таємниці зникнення батька.
- **Сюжетна лінія (7 розділів)**:
  1. *Розділ 1 — «Сон»*: Темний цвинтар під дощем, таємнича тінь батька, шепіт «Він... там... лопата...», раптовий підйом тривоги (+10) та пробудження.
  2. *Розділ 2 — «Вечір удома»*: Скромний теплий будинок, хвора мати Сюзі потребує ліків, розмова про зниклого батька; вибір подарунка для сестрички Ребеки (цукерки / ведмедик / набір для малювання); вихід під дощ.
  3. *Розділ 3 — «Лісова дорога»*: Нічний ліс, туман, зустріч із підозріло ввічливим сусідом Джиммі (вибір відповідей); звуковий дежавю-глітч (+15 тривоги).
  4. *Розділ 4 — «Місто»*: Аптека та магазин, купівля необхідного; моторошне видіння на зворотній дорозі — силует Джиммі з лопатою, різкий спалах та втеча (+25 тривоги).
  5. *Розділ 5 — «Ліки»*: Повернення додому, допомога мамі, вручення вибраного подарунка Ребеці з персоналізованими реакціями.
  6. *Розділ 6 — «Місце зі сну»*: Наступний похмурий день, пошук місця в лісі, свіжа могила та лопата; розслідування; раптовий удар у спину від Джиммі («Тобі тут не місце. Ти забагато бачив»).
  7. *Розділ 7 — «Пробудження»*: Повернення свідомості вдома, страшне відкриття правди від Сюзі («Джиммі сказав...»), шепіт батька «Дякую...», фінальні титри та можливість повторного проходження.

## 2. Візуальний дизайн та взаємодія

- **Візуальний стиль**:
  - Палітра: 60% глибокий нічний нейтрал (`#060913`, `#0d1322`), 30% атмосферні поверхні (силуети ялин, туманні шари, дерев'яні балки будинку), 10% теплий акцент (бурштинове світло ліхтаря, вікна будинку, вітрина аптеки) та тривожні червоні спалахи видінь (`#ef4444`).
  - 5-шаровий паралакс: хмарне небо з блискавками $\rightarrow$ далекий гірський ліс $\rightarrow$ середній ялиновий ліс $\rightarrow$ дорога з калюжами й травою $\rightarrow$ передній план із темними гілками.
  - Динамічне світло: кругова маска навколо Боба з плавним градієнтом, затуханням («диханням») та мерехтінням при зростанні тривоги.
  - Ефекти часток: процедурний дощ з бризками на землі, клуби туману, плівковий шум (film grain) через піксельні маніпуляції.
- **Шкала тривоги (0–100)**:
  - Без числових показників на екрані. Впливає на пришвидшення серцебиття у Web Audio, посилення шуму, радіус та тремтіння ліхтаря, частоту візуальних глітчів.
- **Інтерфейс**:
  - Напівпрозора мінімалістична діалогова панель знизу екрана з силуетом мовця та моноширинним бейджем імені.
  - Меню паузи, налаштування звуку (музика/ефекти), автозбереження прогресу в `localStorage`.

## 3. Ключові технічні рішення

- **Повна процедурна автономність (Zero Assets)**: Жодних зовнішніх `.png` або `.mp3` файлів. Всі спрайти персонажів (Боб, Сюзі, Ребека, Джиммі, тінь батька), декорації та анімації ходьби малюються безпосередньо через 2D Context API.
- **Синтезатор звуку (Web Audio API)**:
  - Генератор шуму (White noise + BPF/LPF) для дощу та поривів вітру.
  - Субгармонічний FM/Sine синтезатор для низького фонового дрону.
  - Пульсуючий осцилятор серцебиття з частотою, прив'язаною до поточної тривоги (60–140 BPM).
  - Спеціальні звуки кроків (різні частотні спектри для трави/багна, дерев'яної підлоги та калюж).
  - Музична тема будинку (заспокійливі арпеджіо) та дисонантні стінгери видінь (Square/Sawtooth з експоненційним спадом).
- **Збереження стану**: Використання `localStorage` для збереження глави, накопиченої тривоги та прапорців вибору (`giftChoice`, `jimmyDialogueChoice`).

## 4. Архітектура та структура компонентів

```
┌─────────────────────────────────────────────────────────────────┐
│                           App.tsx                               │
│  (Управління станом гри: Меню, Геймплей, Титр глави, Пауза)     │
└────────────────┬───────────────────────────────┬────────────────┘
                 │                               │
┌────────────────▼──────────────┐ ┌──────────────▼────────────────┐
│         GameCanvas.tsx        │ │          DialogueBox.tsx      │
│  - Головний цикл requestAnim  │ │  - Ефект друкарської машинки  │
│  - 5-шаровий паралакс         │ │  - Варіанти вибору реплік     │
│  - Силуети та ходьба          │ │  - Портрет та ім'я спікера    │
│  - Освітлення ліхтаря         │ └───────────────────────────────┘
│  - Дощ, туман, глітчі, спалахи│
└────────────────┬──────────────┘
                 │
┌────────────────▼──────────────┬─────────────────────────────────┐
│        SoundEngine.ts         │        StoryScript.ts           │
│  - Web Audio Context          │  - Дані діалогів 7 розділів     │
│  - Дощ, кроки, серцебиття     │  - Умови переходів та виборів   │
│  - Дрони, мелодії, стінгери   │  - Зміна рівня тривоги          │
└───────────────────────────────┴─────────────────────────────────┘
```

### Модель стану гри
- `gameState`: `'MENU' | 'PLAYING' | 'CHAPTER_TITLE' | 'PAUSED' | 'CREDITS'`
- `chapter`: `1 | 2 | 3 | 4 | 5 | 6 | 7`
- `anxiety`: `number` (0–100)
- `flags`: `{ giftChoice?: 'sweets' | 'teddy' | 'art_set', jimmyChoice?: 'honest' | 'evasive' | 'silent', pharmacyBought?: boolean, storeBought?: boolean, inspectedGrave?: boolean }`
- `inventory`: `string[]` (Ліхтар, Ліки, Подарунок)
- `controls`: клавіатура (A/D, Стрілки, E, Пробіл) та віртуальний екранний D-pad для мобільних пристроїв.
